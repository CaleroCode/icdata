¡Hola, soy Iván Calero!
Doy forma a ideas con imagen y código.

Soy un profesional creativo con amplia experiencia en el uso de la suite Adobe, especializado en Photoshop, After Effects, Premiere y Lightroom, herramientas con las que he desarrollado proyectos de diseño visual y edición. Mi trayectoria como fotógrafo de fauna salvaje me ha permitido perfeccionar mi mirada artística, la atención al detalle y la capacidad para contar historias a través de imágenes.

Cuento también con experiencia en funciones administrativas, lo que me ha dotado de habilidades organizativas, gestión de proyectos y trabajo en equipo. Durante los períodos en los que no ejercí funciones creativas, trabajé en el sector metal, experiencia que me permitió adquirir competencias para soportar la presión, manejar el estrés y gestionar el trabajo de forma eficiente.

Actualmente, estoy ampliando mis horizontes profesionales y tecnológicos al cursar un bootcamp para convertirme en desarrollador full stack, un camino que me permite unir mi perfil creativo con el mundo del desarrollo web y la programación. Mi objetivo es integrar mi experiencia visual con las soluciones digitales, creando proyectos que combinen diseño, funcionalidad y tecnología.

EM-PULSE

Plataforma web para sensibilizar sobre la esclerosis múltiple

Tecnologías

Django 5.2+ Django REST Framework React 19 + Vite Tailwind CSS PostgreSQL (Neon) Lucide React Icons Hugging Face IA NewsAPI Token Authentication Gunicorn

https://empulse.onrender.com

¿Qué es EM-PULSE?

EM-PULSE es una plataforma web integral creada con el propósito de sensibilizar y educar sobre la esclerosis múltiple, una enfermedad que afecta a millones de personas alrededor del mundo.

Mi objetivo

Ayudar a familiares, amigos y el entorno cercano de las personas diagnosticadas con EM a entender mejor los síntomas, los desafíos diarios y las realidades de vivir con esta condición. La empatía y la comprensión son clave para una mejor calidad de vida.

Lo que aprendí

  • Full Stack Development - Arquitectura completa backend-frontend-database integrada
  • Backend con Django + Django REST Framework - APIs RESTful robustas y escalables
  • Frontend con React 19 + Vite - Interfaces reactivas, optimizadas y modernas
  • Bases de datos - SQLite en desarrollo, PostgreSQL en producción (Neon)
  • 6 módulos educativos completos - ¿Qué es EM?, Tipos, Síntomas, EM-FORMA, Salud Mental, Derechos
  • Foro comunitario - Publicación de posts, comentarios, likes y búsqueda avanzada
  • Integración con APIs externas - NewsAPI (noticias actuales) y Hugging Face (chat IA)
  • Accesibilidad WCAG 2.1 AA - Cumplimiento de estándares para múltiples discapacidades
  • Personalización de accesibilidad - Modo oscuro/claro, tamaño de fuente (80%-160%), movimiento reducido
  • PWA (Progressive Web App) - Instalable sin App Store, funciona offline, caché inteligente con Service Workers
  • Compartir en redes sociales - Integración con Twitter/X, Facebook, WhatsApp, LinkedIn, Email y copia de enlace
  • Newsletter y suscriptores - Sistema de suscripción personalizado
  • Búsqueda avanzada - Filtrado por tipo (posts, noticias, síntomas) y ordenamiento
  • Exportación a PDF - Descarga de contenido con marca de agua EM-PULSE
  • SEO optimizado - Sitemaps XML, meta tags descriptivos, estructura semántica HTML5
  • Cumplimiento legal - GDPR compliant, Política de Privacidad, Términos de Servicio, descargo médico
  • Admin Django personalizado - Gestión de contenido, usuarios y moderación
  • Autenticación por Token - Django REST Framework con seguridad
  • Diseño responsive - Mobile-first, funcionando perfectamente en Android, iOS, Windows y Mac
  • Rendimiento optimizado - Lazy loading, caché de datos, minificación, load time <2s
  • Deployment en producción - Render (backend) + Neon PostgreSQL, HTTPS automático, deploy automático con git push
  • UX/UI centrado en usuario - Diseño empático, dark theme profesional, transiciones suaves, modales intuitivos
  • Estado global y componentes reutilizables - Gestión eficiente de estado en React

Este proyecto fue fundamental en mi formación como desarrollador full stack, demostrando que la tecnología puede ser una herramienta poderosa para el bien social.

¿Qué es una PWA?

Una Progressive Web App (PWA) es una aplicación web que funciona como una app nativa. Se instala directamente desde tu navegador sin necesidad de acceder a la App Store.

  • ✅ Se instala en segundos desde tu navegador
  • ✅ Funciona sin conexión a internet
  • ✅ Ocupa muy poco espacio en tu dispositivo
  • ✅ Acceso rápido como una app nativa
